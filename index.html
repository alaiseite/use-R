💡 自定义 API 配置教程

为什么推荐自己配？
免费公共接口经常拥堵卡顿，如果你填入自己的大模型 API（如 DeepSeek、智谱），不仅速度秒回、翻译极度精准，还能解决照片识别的错字问题，且费用极低（几块钱能用半年）！

第一步：获取 API Key

推荐去 DeepSeek 开放平台 (platform.deepseek.com) 或 智谱AI (open.bigmodel.cn) 注册账号。进入控制台，找到“API Keys”，点击创建并复制你的密钥（以 sk- 开头的字符串）。

第二步：填写配置

点击本页面右上角的 ⚙️ 齿轮 图标，勾选最下方的“✨ 自定义大模型 API”，然后填入：

1. 接口地址（以 DeepSeek 为例）：

https://api.deepseek.com/v1/chat/completions

2. API Key：粘贴你刚才复制的 sk- 开头的密钥。

3. 模型名称：
如果只用来翻译文本，填 deepseek-chat；
如果想用来拍照提取文字，必须填支持视觉的模型，比如智谱的 glm-4v 或 通义的 qwen-vl-plus。

第三步：保存并使用

点击“保存设置”。现在你点照片解析，会直接调用云端极速识别！

注：如果你在网页直接双击打开 (file:// 协议)，浏览器可能会拦截大模型请求（跨域）。建议部署到 GitHub Pages 或本地服务器运行。

👋 详细使用须知

🌐 一、 最佳浏览器推荐

强烈建议您使用微软 Edge 浏览器！
Edge 内置了微软神经网络语音，发音音质最高且对音频接口的跨域限制最少。
💡 若在微信内打开可能没声音，请点击右上角选择“在浏览器中打开”。

🔊 二、 翻译与发音机制

  • 全自动模式： 翻译会在后台同时请求多个免费通道，谁先返回用谁。若全挂，点右上角 ⚙️ 换通道。
  • 无需语音包： 发音使用的是网络直连，无需在手机系统里下载俄语包。如果没声，请检查网络。

🖼️ 三、 照片解析功能

  • 耗时较长： 纯浏览器本地识别约需 2-3 分钟，首次需下载字库。
  • 更优替代方案： 直接用手机自带的相册“提取文字”，或发给“豆包”提取，然后把俄文粘贴到上方文本框。这比本地解析准得多也快得多！

如果以后忘了怎么操作，随时点击左上角的 ❓ 即可重新阅读本说明。
